Instructions de Test WebRTC :

  1. Ouvrez 2 onglets côte à côte : un pour le vendeur, un pour le client
  2. Attendez la connexion : Les 2 pages doivent afficher "Connecté"
  3. Testez l'appel : Sur la page vendeur, cliquez sur "Appeler le client"
  4. Vérifiez la sonnerie : Le client doit entendre la sonnerie et voir la notification
  5. Répondez : Sur le client, cliquez sur "Répondre"
  6. Testez le chat : Envoyez des messages dans les 2 sens
  7. Contrôles audio/vidéo : Testez les boutons de mute et camera

🔧 Informations Techniques :

Si les liens ne fonctionnent pas, vérifiez que les serveurs sont bien démarrés :

Frontend: http://localhost:3007
WebSocket: ws://localhost:3001

WebRTC corrigé avec : Sonnerie réelle, notifications synchronisées, chat en temps réel
