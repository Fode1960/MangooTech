# Mini-Boutique Mangoo - Application E-commerce Complète

## 🎯 Description
Application e-commerce moderne et complète avec système de gestion des produits, panier, commandes et authentification.

## ✨ Fonctionnalités Principales

### 🛍️ Boutique
- **Catalogue de produits** avec images et descriptions
- **Système de panier** avec gestion des quantités
- **Processus de commande** complet avec validation
- **Gestion des stocks** en temps réel

### 🔐 Authentification
- **Système de connexion** sécurisé
- **Routes protégées** pour l'administration
- **Gestion des sessions** utilisateur

### 📊 Administration
- **CRUD complet** des produits
- **Gestion des commandes** avec statuts
- **Tableau de bord** avec statistiques
- **Système de pagination** avancé

### 🎨 Design
- **Charte graphique Mangoo** complète
- **Mode Jour/Nuit** avec transitions fluides
- **Design responsive** et moderne
- **Animations** et effets visuels

## 🚀 Technologies Utilisées

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS + Design System Mangoo
- **Build**: Vite
- **Routing**: React Router DOM
- **State Management**: React Context + Zustand
- **Icons**: Lucide React

## 📦 Installation & Lancement

```bash
# Installation des dépendances
npm install

# Lancement en développement
npm run dev

# Build pour la production
npm run build

# Prévisualisation du build
npm run preview
```
