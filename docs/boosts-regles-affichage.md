# Boosts MangooTech — Règles d’affichage (1 page)

Ce document définit où et comment s’affichent les Boosts pour que l’expérience soit simple, cohérente, et mesurable.

## Les 3 Boosts (intention vendeur)

### 1) Boost Carte (Local+)
- Intention : « Être vu autour de moi »
- Type : visibilité géolocalisée
- Emplacement principal : Local+ (Carte)

### 2) Boost Vitrine (Sponsorisé)
- Intention : « Être vu par tous quand on découvre »
- Type : visibilité premium sur écrans de découverte
- Emplacements principaux : Accueil + Marketplace + Boutiques

### 3) Boost Promo (Promotion + Nouveau)
- Intention : « Mettre en avant une offre / nouveauté »
- Type : visibilité produit/actus
- Emplacements principaux : Marketplace + Fiche boutique

## Écrans officiels
- Accueil
- Marketplace
- Boutiques (liste)
- Recherche
- Fiche boutique
- Local+ (carte)

## Matrice d’affichage (où apparaît quoi)

### Boost Carte (Local+)
- Local+ (Carte) : affichage sur la carte, prioritaire autour de l’utilisateur
- Local+ (Liste Boutiques/Métiers) : remonte dans les résultats autour de l’utilisateur
- Accueil / Marketplace / Boutiques / Recherche / Fiche boutique : optionnel (badge « Boost Carte actif »), non nécessaire

Condition : localisation fiable (GPS/quartier/point carte). Sans localisation fiable, pas d’affichage sur carte.

### Boost Vitrine (Sponsorisé)
- Accueil : section « Sponsorisé »
- Marketplace : section « Sponsorisé »
- Boutiques (liste) : épinglé en haut
- Recherche : résultats sponsorisés en haut
- Fiche boutique : badge « Sponsorisé » + CTA
- Local+ : non requis (sauf si vous voulez afficher un badge, sans priorité carte)

Condition : aucune (fonctionne même sans GPS).

### Boost Promo (Promotion + Nouveau)
- Marketplace : sections « Promotions » et « Nouveautés »
- Accueil : blocs « Promotions » et « Nouveautés »
- Boutiques (liste) : filtres/onglets « Promo » / « Nouveau »
- Recherche : filtres « Promo » / « Nouveau » + labels
- Fiche boutique : badge « Promo » / « Nouveau » + section dédiée
- Local+ : optionnel (badge), pas l’objectif principal

Condition :
- Promotion : au moins 1 produit/offre avec remise
- Nouveau : boutique créée récemment (ex: 7 ou 14 jours) ou nouveaux produits publiés

## Transparence (obligatoire)
- Tout placement payant est étiqueté clairement : « Sponsorisé », « Promo », « Nouveau ».

## Quotas et priorités (recommandés)
- Accueil / Marketplace : 4–6 cartes max par section, puis rotation
- Boutiques (liste) : 2 sponsorisés max épinglés
- Recherche : 1–2 sponsorisés max

Priorité quand plusieurs contenus existent :
1) Sponsorisé (Boost Vitrine) dans les emplacements sponsorisés
2) Promo/Nouveau dans leurs sections
3) Boost Carte uniquement sur Local+ (carte/liste autour)

## Mesure minimale (facile)
- Impression : la carte sponsorisée a été affichée
- Clic : clic sur la carte / sur « Voir » / sur CTA
- Action : Discuter / Itinéraire / Achat / Demander livraison

## Promesses simples (textes prêts à l’emploi)

### Côté vendeur
- Boost Carte : « Apparaissez en premier autour de vous sur la carte. »
- Boost Vitrine : « Soyez mis en avant sur Accueil / Marketplace / Boutiques. »
- Boost Promo : « Mettez vos promotions et nouveautés en avant. »

### Côté client
- Local+ : « Découvrez les meilleures boutiques et métiers autour de vous. »
- Sponsorisé : « Des commerçants mis en avant pour vous faire découvrir de bonnes adresses. »
- Promo/Nouveau : « Repérez rapidement les promotions et nouveautés du moment. »
