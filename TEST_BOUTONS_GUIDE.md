- ✅ **Cliquez sur le bouton** pour ouvrir dans une nouvelle fenêtre

### 3. **Onglet Live Shopping** 📺

## 🎯 **Fonctionnalités à Tester**

### Dans le Chat:
```
1. Ouvrez une conversation
2. Cliquez sur 📞 (Appel Audio)
3. Cliquez sur 🎥 (Appel Vidéo)
4. Envoyez des messages
5. Partagez des fichiers
```

### Dans Appels Vidéo:
```
1. Activez/désactivez la caméra
2. Activez/désactivez le microphone
3. Testez le partage d'écran (simulé)
4. Mode plein écran
5. Suivez la durée d'appel
```

### Dans Live Shopping:
```
1. Sélectionnez une session (Smartphones, Mode, Électroménager)
2. Observez l'animation canvas
3. Voyez les viewers simulés
4. Regardez les achats en temps réel
5. Utilisez le chat intégré
```
